## 3. Что проверено и работает

### Витрина и каталог
- 32 маршрута, 61 внутренняя ссылка, 0 битых; 404 отдаёт корректную страницу.

- Поиск с debounce и подсказками (на static — по `products.json`).
- Полная версия: фильтры, сортировка, пагинация, счётчики категорий.
- Адаптив 320/360/390/768/1024/1440 — без горизонтального скролла.

### Корзина и checkout
- Добавление, изменение количества, удаление, очистка, сохранение в localStorage.
- Самовывоз и доставка, зоны/стоимость/бесплатный порог, даты и интервалы.
- Промокоды, бонусы (списание до 50%, клампинг по балансу), валидация полей.
- Онлайн-оплата (демо), success page, статус, письмо-заглушка.
- Полная версия: заказ создаётся, остатки уменьшаются, бонусы начисляются после оплаты.

### Авторизация и кабинет
- Регистрация, welcome 300 бонусов, дубликат email 409, слабый пароль 422.
- Вход/выход, профиль, адреса, история заказов, бонусный счёт, уровни.
- Восстановление пароля: одноразовый токен, повторное использование 400, старый пароль 401.
- IDOR: чужой заказ — 403.

### Админка
- Роли: customer → `/account`; manager — read-only users; admin — полный доступ.
- Создание/редактирование/скрытие/удаление товара, категории, промокода.
- Смена статуса заказа, CSV-экспорт (BOM, 58+ строк), CSV-импорт с BOM.
- Дашборд: выручка, заказы, средний чек, топ товаров, график.

### API и безопасность
- Подмена цены игнорируется (сервер считает сам).
- Отрицательное/нулевое количество и oversell — 409.
- Превышение бонусов клампится; промокод проверяется по сумме/сроку/лимиту.
- SQL-инъекция в поиске — 0 результатов, без ошибки.
- Rate limit логина — 429 после 8 попыток.
- Cookie `HttpOnly`, `SameSite=Lax`; `X-Content-Type-Options`, `X-Frame-Options`.
- Демо-оплата и reset-ссылка закрыты в production (см. P0).

## 4. Доступность (axe-core 4.10.2, WCAG 2.1 AA)

Проверены `/`, `/catalog`, `/product`, `/cart`, `/checkout`, `/loyalty`, `/contacts`.

**Исправлено:**

- `aria-label` на рейтинге без роли → добавлен `role="img"`;
- табы на карточке товара без `tablist` → добавлены `tablist/tab/tabpanel`, `aria-controls`;
- `muted` затемнён до `#5F666B`, чтобы убрать 4.25:1 на светлом фоне.

**Осталось:** `color-contrast` — 4–30 узлов на страницу. Ключевые пары:

| Пара | Контраст | Норма |
|---|---|---|
| `#FFFFFF` на `#99B415` | 2.36:1 | 4.5:1 |
| `#7E9A0E` на `#FFFFFF` | 3.22:1 | 4.5:1 |
| `#FF9B9B` на `#5F7A08` | 2.43:1 | 4.5:1 |
| `#72777C` на `#F7F8F9` | 4.25:1 | 4.5:1 |

Рекомендация: для лаймовых кнопок/hero использовать тёмный текст `#1A1A1A` (контраст ≈ 5.7:1) либо затемнить фон до `#5F7A08`; для ссылок — `brand-900`.

## 7. Рекомендации по приоритетам

**До production (P0/P1):**
1. Подключить боевые ЮKassa, SMTP, SMS.RU, Яндекс.Метрику/GA4; задать `AUTH_SECRET`, `DEMO_PAYMENTS=false`.
2. Реализовать возвраты ЮKassa и state machine заказов.
3. Закрыть контраст WCAG AA (тёмный текст на лайме или тёмный лайм).
4. Оптимизировать mobile LCP: WebP/AVIF, responsive sizes, облегчить/убрать демо-баннер, проверить шрифты.
5. Подключить 1С или согласовать CSV-процесс на приёмке.
6. Заменить демо-контакты, фото, отзывы, рейтинги, юридические документы.

**До публичного запуска (P2):**
- TTL резерва остатков и автоотмена неоплаченных заказов;
- click-to-load для Яндекс.Карты;
- ссылка на АЗС, новости, cookie-consent;
- sitemap с trailing slash, 400 вместо 500 для form-encoded;
- увеличить touch-targets в футере.

**P3:** избранное, демо-баннер, Instagram, мелкие SEO/UX-шероховатости.
