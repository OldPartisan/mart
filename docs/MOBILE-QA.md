# QA-аудит Android-приложения «Ирбис Март»

**Дата:** 3 ноября 2026  
**Сборка:** `ru.irbis.mart` 1.0.0 (debug), Android 15 / API 35, arm64  
**Метод:** установка APK на эмулятор, ручные сценарии, WebView CDP, скриншоты, проверка DOM/layout, offline-режим, hardware back.

## Итог

Найдено **6 дефектов отображения** и **3 UX-ограничения**. Критичные дефекты исправлены, APK пересобран и проверен.

| ID | Severity | Дефект | Статус |
|---|---|---|---|
| M-01 | **P0** | Каталог на мобильном: фильтры — flex-ребёнок, растягивались на всю высоту и оставляли товарам ~75 px; контент уезжал вправо и обрезался (`scrollWidth 489` при viewport 412) | **Исправлено** |
| M-02 | **P1** | Карточка товара: табы «Описание/Состав/…» не сжимались, карточка расширяла страницу до 447 px; горизонтальный скролл | **Исправлено** |
| M-03 | **P1** | Android 15 edge-to-edge: контент под status bar, время/заряд не видны; шапка прижата к нулю | **Исправлено**: insets + фирменный status bar |
| M-04 | **P1** | Offline-экран: битая иконка логотипа (`logo.png` резолвился в remote 404) | **Исправлено**: data URI |
| M-05 | **P2** | На `/login` в production показывался блок «Демо-доступ» с устаревшим `Admin123!` | **Исправлено**: блок только вне production |
| M-06 | **P2** | Карточки товаров в 2 колонки: 5 звёзд + счётчик отзывов не давали весу поместиться, «900 мл» и «на 3–4 человек» переносились/обрезались | **Исправлено**: компактный рейтинг на mobile |
| M-07 | P2 | Hero на главной занимает ~70% экрана: товары не видны без скролла | Открыто (UX-решение) |
| M-08 | P2 | В приложении остаются сайтовые header/footer; нет нижней навигации и нативных экранов | Нижняя навигация добавлена; нативные экраны — открыто |
| M-09 | P3 | Часть ссылок/иконок меньше 44×44 (breadcrumbs, delete, footer) | Открыто |
| M-10 | P3 | Нет pull-to-refresh и offline-каталога; offline-экран только при ошибке загрузки | Pull-to-refresh добавлен; offline-каталог открыт |

## Проверенные сценарии

- холодный запуск, splash, иконка, status bar;
- главная, скролл, карусель, категории;
- бургер-меню, переход в каталог;
- каталог: фильтры/сортировка, карточки, цены, рейтинг;
- карточка товара: галерея, табы, добавление в корзину;
- корзина: количество, удаление, итог;
- checkout: контакты, самовывоз/доставка, поля;
- login: поля, клавиатура, скрытие демо-доступа;
- hardware back: возврат по истории WebView;
- offline: отключение сети, fallback, повтор;
- safe-area: status bar и нижний gesture bar.

## Что проверено технически

- `scrollWidth == clientWidth` на `/`, `/catalog/`, `/product/*`, `/cart/`, `/checkout/`, `/login`, `/loyalty/`, `/delivery/`, `/contacts/`, `/cafe/`, `/promotions/`;
- 0 битых изображений;
- 0 JS-ошибок в WebView;
- APK: `aapt dump badging` — package `ru.irbis.mart`, minSdk 23, targetSdk 35;
- `apksigner verify` — debug-подпись;
- `adb install` — Success;
- offline-экран отображает логотип и кнопку «Повторить».

## Ограничения

- тестирование на эмуляторе Android 15, не на физических устройствах;
- iOS не проверялся;
- полный заказ внутри WebView не оформлялся (checkout API проверен на сайте); WebView использует тот же backend;
- платежи ЮKassa в приложении не прогонялись (демо-режим);
- push, deep links, биометрия не реализованы.

## Рекомендации

1. Для production — release-подпись/AAB, RuStore/Google Play.
2. Убрать демо-доступы и тестовые данные из production.
3. Добавить нижнюю навигацию или нативные экраны (React Native/Expo) для app-like UX.
4. Подключить FCM push, offline-каталог, deep links и Custom Tabs для оплаты.
5. Проверить на Android 6/10/13/15 и iOS.
